# 📸 Споделена Галерия & Видео Трейлър

Елегантна, бърза и много лесна за употреба галерия на български език, готова за публикуване във **Vercel**.

## 🌟 Основни възможности

1. **Бутон 1: "Качи снимки" (Upload)**
   - Качване на една или множество снимки едновременно директно от мобилен телефон (камера / галерия) или компютър.
   - Предварителен преглед на избраните снимки.
   - 🔒 **Сигурност**: Посетителите могат само да качват и свалят снимки — няма бутон за изтриване, така че спомените остават непокътнати.

2. **Бутон 2: "Галерия" (Gallery)**
   - Преглед на всички качени снимки в адаптивна решетка.
   - Пълноекранен преглед (Lightbox) с навигация предишна/следваща снимка.
   - ⬇️ **Бутон "Свали снимката" горе вдясно**: Записва оригиналната снимка директно в галерията на телефона или в паметта на компютъра с един клик.

3. **Бутон 3: "Трейлър" (Trailer)**
   - Модерен видео плейър с пълен контрол за 3-минутно видео.
   - Можете да поставите собствен файл `trailer.mp4` в папката `public/` или да въведете линк директно от интерфейса.

## 🚀 Локално стартиране (Development)

1. Инсталиране на зависимостите (ако вече не са инсталирани):
   ```bash
   npm install
   ```

2. Стартиране на тестовия сървър:
   ```bash
   npm run dev
   ```

3. Отворете браузъра на:
   ```
   http://localhost:3000
   ```

## ☁️ Как да качите проекта във Vercel (Стъпка по стъпка)

### Вариант 1: Чрез GitHub (Препоръчително)

1. **Създайте ново хранилище (repository) в GitHub** (напр. `desi-gallery`).
2. **Пушнете проекта в GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Първоначална версия на галерията"
   git branch -M main
   git remote add origin https://github.com/ВАШЕТО_ПОТРЕБИТЕЛСКО_ИМЕ/desi-gallery.git
   git push -u origin main
   ```
3. **Импортирайте проекта във Vercel**:
   - Отворете [vercel.com](https://vercel.com) и влезте с профила си.
   - Натиснете **"Add New..."** -> **"Project"**.
   - Изберете хранилището от GitHub и натиснете **"Deploy"**.
4. **Активирайте Vercel Blob за съхранение на снимките (Само с 1 клик!)**:
   - В контролния панел на проекта във Vercel отидете на раздела **"Storage"**.
   - Натиснете **"Create Database"** и изберете **"Blob"**.
   - Дайте име (напр. `gallery-blob`) и натиснете **"Create"**.
   - Vercel автоматично ще създаде променливата `BLOB_READ_WRITE_TOKEN` за вашия проект.
   - Натиснете **"Redeploy"** или направете нов push – готово! Всички качени снимки от гостите ще се записват постоянно в облака.

---

### Вариант 2: Директно през Vercel CLI (от терминала)

1. В конзолата изпълнете:
   ```bash
   npx vercel
   ```
2. Следвайте инструкциите за вход и изберете настройките по подразбиране (Enter).
3. За продукция:
   ```bash
   npx vercel --prod
   ```
4. В сайта на Vercel влезте в проекта -> **Storage** -> създайте **Blob** база данни.
